# Volluto Estoque Pro v5 — Visual

Versão redesenhada para ficar visualmente próxima ao protótipo fornecido:
- painel inicial azul-marinho e amarelo
- imagem institucional da Volluto na tela inicial
- cartões grandes para EPI, EPC, Peças, Controle, Movimentações, Inventário, Reposição, Relatórios, Usuários, QR Code, Backup e Alertas
- barra inferior estilo aplicativo mobile
- mantém os recursos funcionais da v4
- funciona como PWA e pode ser instalada no Android via GitHub Pages

## Instalação
Envie todos os arquivos desta pasta para a raiz do repositório no GitHub.
Ative Settings > Pages > Deploy from a branch > main > /(root).
Abra o endereço do GitHub Pages no Chrome e escolha Instalar aplicativo / Adicionar à tela inicial.
